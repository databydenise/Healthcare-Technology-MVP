# Team Roles

The project is being developed by a cross-functional team spanning product,
design, analytics, marketing, frontend, and backend development.

| Function | Responsibility |
|---|---|
| Project Lead | Cross-functional coordination, planning, progress tracking, and delivery |
| Product Management | Problem definition, product hypothesis, sprint planning |
| Product Design | UX/UI design, accessibility, and interface clarity |
| Data Analytics | User pain points, data analysis, trends, and product metrics |
| Digital Marketing | User demographics, health behavior research, and activation strategy |
| Frontend Development | Dashboards, input forms, and frontend/API integration |
| Backend Development | APIs, user data handling, reminders, logs, and analytics |

## Project Leadership

The Project Lead coordinates communication and progress across the different
functions and helps keep the team aligned toward the MVP submission.
